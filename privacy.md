# Privacy Policy

**Last updated: September 27, 2026**

## Overview

Rclone Google Drive is a personal application used by the application owner to access their own Google Drive files through rclone on their personal computer.

This application is not offered as a public service and is not intended for use by other users.

## Google User Data

The application uses Google OAuth 2.0 to obtain authorization to access the application owner's Google Drive.

Google Drive access is used solely to allow rclone to access and manage the owner's files as instructed by the owner.

## Data Storage

This application does not operate an independent server or database for collecting Google user data.

Authentication credentials and configuration associated with rclone are maintained on the application owner's computer.

## Data Sharing

Google user data accessed through this application is not sold or shared with third parties by this application.

## Data Use

Google Drive access is used only for the functionality requested by the application owner, including accessing, creating, modifying, and managing files in their own Google Drive.

## Contact

Questions about this privacy policy may be directed to the developer contact email specified in the application's Google OAuth configuration.
