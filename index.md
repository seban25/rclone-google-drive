# Rclone Google Drive – Personal Application

This website provides information about a personal Google Drive integration used with rclone.

## Purpose

This application is used solely by the application owner to access and manage their own Google Drive files through rclone on their personal computer.

The application is not offered as a service to the public and is not intended for use by other users.

## Google Drive Access

The application uses Google OAuth 2.0 to authorize access to the owner's Google Drive account.

Access is used only to enable rclone to interact with the owner's Google Drive files.

Please see the [Privacy Policy](privacy.md) for information about data handling.
